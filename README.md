# Karabu Hub

An online store for clothes, shoes, bags, accessories, perfumes and more.

## Planned features
- Product catalog with categories, sizes and colours
- Search and filters
- Cart and checkout with Paystack
- Order tracking with email and in-app notifications
- Admin dashboard for managing products and orders

## Tech stack
- Web: Next.js
- Mobile: React Native (Expo)
- Backend and database: Supabase
- Payments: Paystack
- Language: TypeScript
